Blocking design issues:
1. Legacy migration cannot safely reuse _projector_from_state unchanged.
   The [migration proposal (line 510)](/home/anduril/Documents/birdtracks/docs/editor-layer-plan.md:510) assumes reconstruction preserves meaning. However, [widget_graph (line 210)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/layout.py:210) applies a presentation sign, while [reconstruction (line 1693)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/widget.py:1693) applies that sign again before installing explicit orders.
   A read-only reproduction using an antisymmetriser with crossed incoming strands returned the negative of the original operator. More importantly, an automatically ordered projector and an explicitly ordered projector with opposite exact values produced identical widget graphs. The graph alone therefore cannot recover the original meaning unambiguously.
   Smallest correction: encode the exact Projector in new saves. For legacy imports, use a matching authoritative algebraic snapshot where available; otherwise document the legacy interpretation and ambiguity. Do not promise lossless recovery or apply a universal extra sign.
2. Ownership must switch completely for each migrated interface.
   The [implementation sequence (line 660)](/home/anduril/Documents/birdtracks/docs/editor-layer-plan.md:660) migrates port commands before movement and postpones removing competing paths. That is safe only if those paths are disabled or bridged immediately for migrated sessions.
   Currently, [JavaScript computes parity (line 2938)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/static/projector-widget.js:2938), the [whiteboard independently flips source signs (line 2731)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/static/whiteboard-widget.js:2731), and [Python accepts unversioned snapshots (line 1269)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/widget.py:1269). Meanwhile, [movement writes presentation traits directly (line 4256)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/static/projector-widget.js:4256). A new Python reorder response could consequently restore older positions or receive another frontend sign compensation.
   Smallest correction: introduce an explicit protocol switch per session. Migrated sessions use one revisioned state publication, bypass legacy sign/save/undo handlers, and bridge remaining presentation edits into that state. JavaScript must reject stale responses and apply accepted state without triggering another command. Save must wait for pending commands to finish.
3. Editor equality must distinguish equivalent drawings.
   The [proposed frozen state and no-op rule (line 407)](/home/anduril/Documents/birdtracks/docs/editor-layer-plan.md:407) leave equality unspecified. [Projector equality (line 480)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/projector.py:480) intentionally ignores compensated orientation differences. A default dataclass containing a Projector therefore compares equal before and after an odd compensated reorder when its other fields are unchanged.
   I reproduced this: the orders and raw coefficients differed, but the containing states compared equal. Using that comparison for no-op detection would discard the redraw or omit its undo transaction.
   Smallest correction: define representation-sensitive editor comparison covering raw coefficient, explicit orders, connectivity, IDs, and presentation, excluding revision. Keep algebraic equality separate. A successful redraw needs one undo entry even when its mathematical value is unchanged.
4. Outer coefficients need an explicit contract through calculation, replacement, and persistence.
   The [term model (line 409)](/home/anduril/Documents/birdtracks/docs/editor-layer-plan.md:409) permits symbolic outer factors, but subsequently proposes deriving a ProjectorSum for calculations. [ProjectorSum accepts rational coefficients only (line 50)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/projector_sum.py:50).
   Existing paths demonstrate the danger: [symbolic result rendering (line 169)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/whiteboard/widget.py:169) puts the symbolic factor into source but encodes only the projector; [generated blocks omit `calculation_value` for symbolic sums (line 1654)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/whiteboard/widget.py:1654), while [expansion expects that value (line 550)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/whiteboard/widget.py:550).
   Smallest correction: specify that (Q, a) means exactly a × Q. Import both members of ordinary sum terms, preserve symbolic sums in their supported domain, and serialize the outer factor. Replacing Q by terms (Rᵢ, bᵢ) must produce factors a × bᵢ exactly once. Existing low-level replacement helpers also require care: [`_substitute_node` (line 365)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/simplification.py:365) returns a unit-coefficient graph; its [caller restores the coefficients (line 239)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/simplification.py:239).
5. Survivor IDs must be captured before collection, with branching semantics.
   The [provenance proposal (line 463)](/home/anduril/Documents/birdtracks/docs/editor-layer-plan.md:463) describes an old-to-new mapping, but expansion can create several descendants, merge equivalent terms, and remove objects. [Current expansion collects and detangles before returning (line 16)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/simplification.py:16); [ProjectorSum combines equivalent representatives (line 50)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/projector_sum.py:50). Original occurrence identity cannot reliably be reconstructed afterward.
   Smallest correction: carry provenance through the rewrite before collection. Scope node/strand identities by term occurrence, support one-to-many descendant mappings, and define which presentation survives an intentional merge. Copy unaffected placement/routes to descendants before laying out new objects. This is required before the structural-edit stage, though it need not delay the initial port command.
6. The existing collection path violates the proposed interactive collapse boundary.
   The plan prohibits full collapse but recommends reusing current expansion/collection paths. [Canvas expansion calls `collect_fully_expanded_permutations` (line 505)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/widget.py:505), which eventually calls [`_collect_equivalent_mixed_projectors` (line 599)](/home/anduril/Documents/birdtracks/src/birdtracks/projectors/simplification.py:599). That function collapses every term when qualifying mixed terms are present. Despite the outer function’s name, this includes unexpanded S/A nodes.
   A read-only probe confirmed collapse calls on both a symmetriser and an S/A–permutation product.
   Smallest correction: provide an editor-safe structural collection path that excludes this fallback. Keep explicitly requested node expansion separate from ordinary editing; collapse must not become command validation, redraw, save, or undo machinery.
